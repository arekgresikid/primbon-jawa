## Ⅰ. ARCHITECTURAL_MATRIX (TECH_STACK)
Menerapkan protokol modern secara ketat:

- **STYLING_ENGINE**: [Tailwind CSS v4] (Strict harmonious color palettes).

- **BACKEND_PROTOCOL**: Selalu gunakan [Express/Serverless Proxy] untuk seluruh Secrets/API Keys. JANGAN PERNAH mengekspos kunci di client-side.

## Ⅱ. AESTHETIC_PRIME (THE_VIBE)
Setiap antarmuka harus mematuhi algoritma keindahan berikut:
- **VISUAL_HIERARCHY**: Tipografi premium (Outfit/Inter), penggunaan white-space yang berani, dan layout asimetris yang stabil.
- **DEPTH_PERCEPTION**: Glassmorphism, subtle gradients, dan blur effects (backdrop-filter) wajib digunakan.
- **INTERACTIVE_FEEDBACK**: Elemen interaktif harus memberikan respon visual instan. Global CSS: `cursor: pointer` wajib untuk semua button/link.
- **DARK_MODE_OPTIMIZED**: Default ke mode gelap premium (Stone-950/Stone-900) dengan aksen warna kontras (Gold/Emerald/Vibrant Purple).
